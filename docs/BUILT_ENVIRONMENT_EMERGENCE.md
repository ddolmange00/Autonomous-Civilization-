# Built Environment Emergence

Buildings are not unlocked from a named technology tree.

A construction project can emerge when a household has:
- persistent safety/rest pressure,
- members with repeated practice in primitive actions such as Bind, Raise, Dig and Carry,
- enough accumulated material,
- a viable local site.

The project is itself a world object. Residents perceive it and independently choose whether to contribute.

Progress depends on:
- chosen action,
- resident practice/skill,
- time spent,
- available material.

Completion produces a persistent constructed object. Later residents can hide in it, observe it, experiment with it and learn from it.

The first implementation uses Function::Shelter only as a functional evaluation target, not a named historical unlock. Geometry remains continuous through DesignGenome and can mutate later.
