# Scale and deep time

Simulation stays individual-first; scale comes from honest coupling,
not headcount inflation.

- civilizations re-derive every step from fission lineage and friendly
  contact ledgers. No assigned archetypes, no fixed borders
- cohorts are off-screen mouths: they eat from the same household
  pools, grow logistically with plenty, starve with famine, and their
  ceiling rises with real granary (storage) capability
- represented population = simulated alive + cohort mouths; it is the
  number the world must actually feed
- causal history compacts into era summaries (births, deaths, battles,
  trades, buildings, contacts) before the log would silently discard it
- scenario presets (default/arid/rich) vary ecological generosity for
  validation breadth; island/colonial topologies remain future work
- 100-year generational smokes run in CI alongside the 5/20-year ones

10k represented is reachable with granaries; 100k+ needs the planned
multi-region world LOD on top of this mechanism.
