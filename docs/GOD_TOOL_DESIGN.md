# God Tool Design

The dock is a world editor, not a cheat menu for civilization outcomes.

Categories:
- Observe: inspect resident/settlement/artifact/creature/terrain.
- Life: resident, animal, monster. Later presets are parameter archetypes, not fixed fantasy classes.
- Nature: vegetation, mineral/material deposit, rain, drought, water/terrain editing.
- Disaster: fire, flood, earthquake, storm, later disease/temperature/extreme events.

Secondary configuration should use a compact contextual popover:
- Life: body scale, speed, fear/aggression, diet, reproduction, intelligence where relevant.
- Vegetation: edible/fiber/wood properties, growth, water demand.
- Mineral: composition hints, hardness/density, abundance.
- Events: radius, intensity, duration.

The player may create extreme entities, but physics/ecology still decide consequences.
Presets are convenience seeds into parameter space; they are not hardcoded behavioral destinies.
