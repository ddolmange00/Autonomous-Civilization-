# Language emergence

Settlements carry a small lexicon: one word per everyday concept
(food, water, danger, shelter, kin, stranger, fire, river, mountain,
spirit, trade, home).

Rules:
- daughter settlements inherit the parent word stock, then drift alone
- isolation diverges vocabularies through small sound changes
- contact blends vocabularies when settlements stay near each other
- divergence is reported per settlement pair (0 = same tongue)

There is no universal translator and no fixed word list.
Mutual unintelligibility is possible and measurable.
