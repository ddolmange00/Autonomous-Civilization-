# World Ground Truth Plan

The world owns objective state; residents own beliefs.

## Objective layers
1. geology: parent rock, ore composition, fractures, elevation, slope
2. soil: texture, organic matter, porosity, hydraulic behavior, stability
3. hydrology: precipitation, infiltration, runoff, groundwater, rivers, flood storage
4. climate: temperature, humidity, wind, radiation, precipitation
5. ecology: vegetation biomass, edible resources, prey, predators, monsters
6. material objects: composition, process history, geometry, damage/fatigue
7. constructed environment: paths, shelters, artifacts and altered terrain

Residents never query these arrays directly. Perception converts nearby truth into noisy PerceivedFeatures; memory and social transmission further distort or improve knowledge.

## Scale
Macro regions generate boundary conditions. Chunk fields update climate/water/soil/biomass. Detailed objects and residents activate near meaningful interaction. This preserves the same causal world while changing computational representation.

## Scientific data
Real-world values seed plausible ranges and calibration, not a mandatory Earth-history script. Alternate world seeds may vary resource abundance and some material distributions while preserving internally consistent physics.
