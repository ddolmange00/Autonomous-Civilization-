# Observation Layer

The player should understand the world without reading a spreadsheet wall.

## Zoom hierarchy
World zoom: settlements, territory, migration, disasters, contacts.
Settlement zoom: population pulse, current awareness, action distribution, local risks, resources, experiments.
Resident zoom: needs, traits, perceptions, memories, relationships, action scores.
Artifact zoom: material/process/genome/performance/lineage.

## Information rule
Show derived summaries first; reveal causal detail on demand.
A settlement card should answer "what is happening?" in seconds.
A resident card should answer "why did this person do that?"
Debug mode may reveal ground truth and scoring internals; normal player mode should only reveal information the player's role could plausibly know.

## Visual rule
World canvas remains dominant. Persistent chrome is limited to time/seed/speed and a compact god-tool dock. Detailed panels are contextual overlays/slides and disappear when dismissed.
